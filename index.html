카드투게더는 공유 예산 관리에 필요한 정보만 처리하며, 광고 판매나 사용자 프로파일링에 이용하지 않습니다.

2. 문자와 캡처 처리

카드 승인·취소 문자 원문은 서버에 보관하지 않습니다. 중복 방지용 SHA-256 해시와 예산 계산에 필요한 구조화된 거래 정보만 저장합니다. 결제예정액 캡처는 iPhone 기기 안에서만 글자를 인식하며 이미지와 인식된 전체 문구를 서버에 전송하거나 보관하지 않습니다.

앱은 문자함 전체를 직접 읽지 않고 사용자가 설정한 단축어가 전달한 문자만 처리합니다. 전송 중 네트워크 오류에 대비하여 카드 문자 원문과 수신 시각을 해당 iPhone의 보호된 키체인에 최대 50건 임시 보관할 수 있습니다. 전송이 완료되면 삭제하며, 72시간이 지난 대기 문자는 다음 앱 또는 단축어 실행 때 폐기합니다. 계정 연결을 해제하면 해당 기기의 대기 문자도 삭제합니다.

3. 이용 목적

결제월별 사용액·예산·결제 예정액 계산, 가족 공유, 알림 전송, 계정 복구, 오류·중복 방지를 위해 이용합니다.

아침 생활비 알림을 켜면 해당 기기의 알림 설정 시간에 목표·사용액·남은 예산을 푸시로 전송합니다. 설정에서 기기별로 알림을 끄거나 시간을 변경할 수 있습니다.

선택 사용 통계 (지원 버전에서만): 처음 화면의 선택 설정이나 ‘우리집 → 사용 통계 공유’에서 직접 켜면, 앱 개선을 위해 임의 식별자, 방문일·방문 횟수, 주요 화면 열기와 설정 완료 여부를 처리합니다. 생활비 화면을 양쪽 기기가 함께 사용하는지 집계할 때만 해당 기기와 가구·참여 역할을 연결하고, 최근 자동 등록 결제가 있었는지 여부를 처리합니다. 사용 통계에 카드 문자, 금액, 가맹점이나 초대코드는 포함하지 않습니다. 기본값은 꺼짐이며 앱 기능 이용에는 영향을 주지 않습니다.

4. 보관 및 삭제

카드·거래·공유 정보는 계정 또는 우리집을 삭제할 때까지 보관합니다. 문자 원문이 없는 연결 진단 정보는 90일 후 삭제합니다. 앱의 설정 ▸ 계정·도움말 ▸ 내 데이터 ▸ 계정 삭제에서 즉시 삭제를 요청할 수 있습니다. 우리집 소유자가 삭제하면 공유 데이터 전체가, 구성원이 삭제하면 본인 계정·기기·참여 정보가 삭제됩니다.

선택 사용 통계는 별도 테이블에 최대 90일 보관합니다. ‘사용 통계 공유’를 끄면 전송을 중단하고 이 앱 설치본의 통계를 지우도록 요청합니다. 오프라인이면 연결 후 다시 요청합니다. 늦게 도착한 전송이 삭제된 기록을 되살리지 못하도록 삭제용 식별자의 별도 해시만 최대 90일 보관합니다.
